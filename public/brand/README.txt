Put your three picture files in THIS folder, with exactly these names:

  sci-files-logo.png    the Sci-Files logo (square works best)
  bcnshs-logo.png       the school logo
  classroom-bg.png      the classroom photo shown very dimly behind the login panel

Until a file is here, the app shows a plain placeholder instead, so nothing looks broken.
After adding files, run "npm run dev" again (or push to GitHub for Vercel).
